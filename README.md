# Retro Pocket · Galaxy S25 Ultra 웹 에뮬레이터 (베타 0.2.0)

게임 화면을 가운데 최대한 크게 놓고, 원본 화면 비율 때문에 남는 좌우 공간에 ROM·강제 저장·불러오기·공략·전체화면·설정 메뉴를 배치한 **개인용 정적 웹앱**입니다.

## 바로 이용하기 (GitHub Pages)

1. 이 ZIP 파일의 내용물 전체를 **새 GitHub 공개 저장소** (예: `retro-pocket`)의 최상위 디렉터리에 올립니다. **ROM, BIOS, 저장 파일은 절대로 올리지 않습니다.**
2. GitHub 저장소 → **Settings → Pages** → **Build and deployment** → **Deploy from a branch** → `main` / `/(root)` → Save.
3. 배포된 `https://<your-username>.github.io/retro-pocket/`에 Galaxy S25 Ultra의 Chrome으로 접속합니다.
4. **ROM** 버튼을 누르고 휴대폰에 저장된 `.gba`, `.sfc`, `.smc`, `.nds`, `.gb`, `.gbc`, `.nes`, `.zip` 파일을 선택합니다. ZIP이면 설정에서 게임기 종류를 지정하고 다시 불러오세요.
5. 실제 게임이 시작되면 **강제 저장 / 불러오기** 버튼을 사용합니다. 슬롯 1~3 선택 및 상태 파일 백업은 더보기에서 관리합니다.
6. Samsung Internet/Chrome 환경에 따라 Android의 **홈 화면에 추가 / 앱 설치**로 바로가기를 만들 수 있습니다.

## 유료 구독 / 서버 / ROM 취급

- 별도의 서버 요금·구독 없음. GitHub Pages에서 **정적 파일만 제공**합니다.
- ROM은 사용자가 휴대폰 파일 선택기에서 **직접 선택**합니다. **사이트로 업로드하지 않으며 GitHub에도 저장하지 않습니다.**
- 게임 실행은 스마트폰 브라우저가 수행합니다. 최초 실행에 필요한 EmulatorJS 코어는 공식 CDN에서 다운로드합니다.
- **베타 0.1.1은 완전 오프라인 실행을 보장하지 않습니다.** CDN을 자체 호스팅·캐싱하는 후속 작업이 필요합니다.
- 게임 저장 상태는 기기 브라우저의 IndexedDB에 저장됩니다. 브라우저 데이터 삭제, 저장 용량 제한 등으로 손실될 수 있으니 더보기의 **백업**을 활용하세요.
- 일반 게임 저장 파일(SAV)과 강제 저장 상태(STATE)는 다릅니다. 별도 게임 내 저장도 병행하는 것을 권장합니다.
- 이미 한글 패치가 적용된 ROM도 파일 자체를 직접 읽기 때문에 추가 패치 절차 없이 실행을 시도할 수 있습니다. 패치별 호환성은 실제 ROM에서 확인해야 합니다.

## 현재 구현된 범위

- GBA, SFC, NDS, GB/GBC, NES 선택
- 모바일 가로모드에서 게임 화면을 원본 비율로 최대한 확대하고 양쪽 메뉴 배치
- ROM 로컬 파일 선택(Blob URL을 통해 같은 출처 iframe에 전달)
- EmulatorJS 공식 CDN `stable` 코어 연결
- 강제 저장/불러오기 3슬롯(IndexedDB + GameManager API)
- 저장 상태 다운로드/복구, 게임별 공략 메모(localStorage)
- 전체화면 요청, 설치형 웹앱 메타데이터

## 아직 검증 또는 구현이 필요한 부분

- 실제 **Galaxy S25 Ultra + 사용자의 한글 패치 ROM + USB-C 게임패드** 조합 실기 QA. 현재 첨부된 ROM이 없으므로 게임 실행/저장 **실기 검증 완료라고 볼 수 없습니다**.
- NDS 일부 게임은 코어/BIOS 호환성이 필요하고 두 화면 배치/터치가 다릅니다.
- EmulatorJS API는 업데이트 시 변경될 수 있어 저장 상태 기능을 실기 테스트해야 합니다.
- 자동 스테이지 인식/공략 자동 업데이트, 진정한 오프라인 실행은 미구현.
- 브라우저의 게임패드 연결 및 버튼 매핑은 에뮬레이터 자체 메뉴에서 확인하세요.

## PC 테스트

이 폴더에서 `python -m http.server 8000` 실행 → `http://localhost:8000/` 접속. `file://` 직접 열기 방식은 지원하지 않습니다.

## 기술 스택 및 출처

- HTML/CSS/JavaScript (프레임워크·빌드 과정 없음)
- [EmulatorJS](https://emulatorjs.org/docs/) (`stable` CDN, 오픈소스, GPL-3.0 계열)
- GitHub Pages (무료 공개 저장소 정적 배포)

## Work 배포용 요청 예시

> 첨부된 `retro-pocket-webapp.zip`을 GitHub 계정 `junsa80`의 **새 공개 저장소 `retro-pocket`**에 업로드하고 GitHub Pages로 배포해 줘. 기존 게임 프로젝트나 game-hub는 변경하지 마. ROM과 BIOS는 업로드하지 마. GitHub Pages 주소가 열리고 모바일 화면 레이아웃이 정상인지 확인하고, 실제 ROM·강제 저장·게임패드는 나중에 내 Galaxy S25 Ultra에서 테스트할 수 있도록 체크리스트를 남겨 줘. 문제가 발견되면 코드를 수정하고 배포까지 진행해 줘.

## v0.1.1 수정 및 검증

- 가로 화면의 여백·메뉴 너비를 반영해 잘림을 방지하고 상하 장식을 축소.
- 슬롯 저장 요청 시 게임과 슬롯을 고정. IndexedDB 트랜잭션 완료 후 성공 표시.
- ROM 교체 중 늦게 끝난 이전 파일 처리 무시, 게임별 메모 전환 전 저장.
- ROM 전체 SHA-256으로 게임별 저장 식별, 같은 파일명 게임의 에뮬레이터 내부 저장 충돌 방지.
- 물리 게임패드 감지 시 터치 버튼 자동 숨김, 연결 해제 시 에뮬레이터 기본 표시로 복원.
- GitHub Pages에서는 멀티스레드 코어를 사용하지 않도록 설정.
- 실제 ROM 실행, 실기 게임패드, 게임 코어의 저장 호환성은 사용자 기기에서 별도 확인 필요.

### 휴대폰 첫 실행 확인
1. 가로 화면에서 ROM을 선택하고 게임 시작. 소리가 없으면 게임 화면을 한 번 누릅니다.
2. 슬롯 1 저장 후 게임 진행 → 불러오기 → 이전 장면 복귀 확인.
3. 브라우저를 다시 열고 같은 ROM 선택 후 슬롯 1 불러오기 확인.
4. 다른 슬롯과 다른 게임의 저장 분리, 백업 다운로드·복구 확인.
5. 게임패드 연결 후 아무 버튼을 누르고 입력·터치 버튼 숨김 확인.
6. 공략 메모 입력 후 다른 게임을 열었다가 원래 ROM으로 돌아와 메모 확인.

## v0.2.0 게임 공략

- 제공된 9개 파일명: OG, OG2, A, R, D, J(GBA), W, K, L(NDS)을 로컬에서 공략에 자동 연결.
- 공략에는 전투·육성·개조의 짧은 요약과 일부 숨겨진 조건을 내장. 숨겨진 조건은 기본 접힘.
- 게임 공략 선택기로 ROM 없이도 열람 가능. 인식 실패 시 직접 선택해 해당 ROM에 연결을 저장.
- 개인 메모는 별도 접힘 영역으로 유지. 기존 저장 상태와 메모 키는 변경하지 않음.
- 현재 장 자동 감지, 모든 회차의 증원·승리 조건, 원문 자동 수집·실시간 갱신은 포함하지 않음.
- 나무위키 직접 접근이 되지 않아 공개 미러에서 확인. 원문 링크·실제 열람본·확인일·기여자·판본 주의를 각 공략에 표시.
- OG/OG2 문서의 PS2판 정보는 제외하고 GBA라고 명시된 내용 중심으로 구성. 일부 숨겨진 조건은 GBA 공략(나무위키 출처 명시)과 대조.
- 요약 데이터는 CC BY-NC-SA 2.0 KR로 제공. 원문 이미지나 본문 전체는 포함하지 않음.
